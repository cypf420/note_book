# 新手引导

## 这个站点是做什么的

  

这是一个本地笔记工作台，用来把网页内容抓取成 Markdown，并继续在浏览器里阅读、编辑、搜索和整理。

适合这些场景：

*   保存课程资料和知识点网页
*   把博客或知识库文章抓成离线笔记
*   用树形分组整理导入资料
*   对导入结果继续编辑和归档

## 核心功能[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E6%A0%B8%E5%BF%83%E5%8A%9F%E8%83%BD)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E6%A0%B8%E5%BF%83%E5%8A%9F%E8%83%BD)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E6%A0%B8%E5%BF%83%E5%8A%9F%E8%83%BD)

### 导入网页[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%AF%BC%E5%85%A5%E7%BD%91%E9%A1%B5)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%AF%BC%E5%85%A5%E7%BD%91%E9%A1%B5)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%AF%BC%E5%85%A5%E7%BD%91%E9%A1%B5)

*   输入网址后，可先导入到编辑区
*   也可以直接导入并保存到站点
*   系统会自动下载网页图片并改写本地引用

### 编辑与保存[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E7%BC%96%E8%BE%91%E4%B8%8E%E4%BF%9D%E5%AD%98)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E7%BC%96%E8%BE%91%E4%B8%8E%E4%BF%9D%E5%AD%98)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E7%BC%96%E8%BE%91%E4%B8%8E%E4%BF%9D%E5%AD%98)

*   支持阅读模式和 Markdown 编辑
*   `Ctrl/Cmd + S` 可保存
*   `Esc` 可退出编辑

### 笔记树[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E7%AC%94%E8%AE%B0%E6%A0%91)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E7%AC%94%E8%AE%B0%E6%A0%91)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E7%AC%94%E8%AE%B0%E6%A0%91)

点击顶部 `笔记树` 按钮后，可以：

*   查看树形分组
*   折叠 / 展开分组
*   拖拽笔记改变顺序
*   拖到其他分组
*   新建分组
*   重命名分组
*   删除空分组

### 搜索[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E6%90%9C%E7%B4%A2)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E6%90%9C%E7%B4%A2)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E6%90%9C%E7%B4%A2)

*   左侧搜索框会搜索全部文档标题和正文

### 删除[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%88%A0%E9%99%A4)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%88%A0%E9%99%A4)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%88%A0%E9%99%A4)

*   删除导入笔记时，会同步清理索引和关联资源

## 保存位置[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E4%BF%9D%E5%AD%98%E4%BD%8D%E7%BD%AE)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E4%BF%9D%E5%AD%98%E4%BD%8D%E7%BD%AE)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E4%BF%9D%E5%AD%98%E4%BD%8D%E7%BD%AE)

*   导入笔记：`content/imports/`
*   网页图片：`content/assets/`
*   索引文件：`content/library.json`

## 启动方式[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%90%AF%E5%8A%A8%E6%96%B9%E5%BC%8F)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%90%AF%E5%8A%A8%E6%96%B9%E5%BC%8F)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E5%90%AF%E5%8A%A8%E6%96%B9%E5%BC%8F)

最简单的方式是双击 `begin.bat`。

启动后看终端提示的网址，一般是：

`http://127.0.0.1:8000`

## 非法操作提醒[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E9%9D%9E%E6%B3%95%E6%93%8D%E4%BD%9C%E6%8F%90%E9%86%92)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E9%9D%9E%E6%B3%95%E6%93%8D%E4%BD%9C%E6%8F%90%E9%86%92)[#](#doc=%E6%96%B0%E6%89%8B%E5%BC%95%E5%AF%BC&section=%E9%9D%9E%E6%B3%95%E6%93%8D%E4%BD%9C%E6%8F%90%E9%86%92)

系统会对以下行为弹出错误提示：

*   空网址或格式错误的网址
*   非法分组名
*   删除未保存的临时内容
*   删除非空分组

看到提示后，按要求修正即可。
