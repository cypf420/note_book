# 新手引导

## 这个站点是做什么的

这是一个本地笔记工作台，用来把网页内容抓取成 Markdown，并继续在浏览器里阅读、编辑、搜索和整理。

适合这些场景：

*   保存课程资料和知识点网页
*   把博客或知识库文章抓成离线笔记
*   用树形分组整理导入资料
*   对导入结果继续编辑和归档

## 核心功能

### 导入网页

*   输入网址后，可先导入到编辑区
*   也可以直接导入并保存到站点
*   系统会自动下载网页图片并改写本地引用

### 编辑与保存

*   支持阅读模式和 Markdown 编辑

> 目前代码块编辑尚在开发种，引用有些许延迟，后面再改吧
> 
> 当前只有块功能没有代码提示和其他东西

*   `Ctrl/Cmd + S` 可保存
*   `Esc` 可退出编辑

### 笔记树

点击顶部 `笔记树` 按钮后，可以：

*   查看树形分组
*   折叠 / 展开分组
*   拖拽笔记改变顺序
*   拖到其他分组
*   新建分组
*   重命名分组
*   删除空分组

### 搜索

*   左侧搜索框会搜索全部文档标题和正文

### 删除

*   删除导入笔记时，会同步清理索引和关联资源

## 保存位置

*   导入笔记：`content/imports/`
*   网页图片：`content/assets/`
*   索引文件：`content/library.json`

## 启动方式

最简单的方式是双击 `begin.bat`。

启动后看终端提示的网址，一般是：

`http://127.0.0.1:8000`

## 非法操作提醒

系统会对以下行为弹出错误提示：

*   空网址或格式错误的网址
*   非法分组名
*   删除未保存的临时内容
*   删除非空分组

看到提示后，按要求修正即可。
