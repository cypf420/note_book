# 新手引导

这是什么

这是一个本地优先的笔记工作台。你可以把网页内容抓成 Markdown，保存到本地，再继续阅读、整理、搜索和编辑。

它适合这些场景：

- 保存课程资料、博客文章、知识库页面
- 把网页内容转成可离线保存的 Markdown
- 用文件树整理自己的笔记和文件夹
- 把本地笔记上传到 GitHub 社区，或者把别人的共享笔记导入到本地

## 第一次使用怎么走

建议按这个顺序：

1. 先看左边最窄一列图标，这里是主导航
2. 打开 `导入与同步`，试一次“获取网页内容”
3. 导入后直接在正文区继续编辑
4. 按 `Ctrl/Cmd + S` 保存
5. 回到 `资源管理器`，在文件树里整理文件夹

## 左侧图标都是什么

左边最窄一列是 Activity Bar。

从上到下常用入口：

- `资源管理器`：看文件树、切换文档、右键操作文件和文件夹
- `搜索`：全文搜索全部笔记
- `导入与同步`：导入网页、上传共享笔记、拉取共享笔记、导出 Markdown
- `Markdown 源码`：打开 Markdown 源码抽屉
- `设置与维护`：保存、删除、文件夹管理、清缓存、退出站点
- `主题切换`：切换浅色 / 深色模式

鼠标停在图标上约 1 秒，会显示名称提示。

## 资源管理器怎么用

资源管理器就是左侧文件树，交互接近 VS Code。

你可以在这里：

- 展开 / 折叠文件夹
- 打开文档
- 新建空白文件
- 新建空白文件夹
- 通过加号菜单直接获取网页内容
- 右键文件夹进行重命名、删除、新建文件
- 右键文件进行打开、重命名、删除

说明：

- 根层不会显示 `editable_note_site`
- `新手引导` 会作为第一个顶层文件夹

## 导入网页怎么用

打开 `导入与同步` 面板后：

1. 输入网页地址
2. 选择“导入到当前编辑区”或“导入并保存到站点”

系统会自动：

- 抓取网页正文
- 下载网页里的图片
- 把内容转成 Markdown

导入后的内容会直接进入所见即所得编辑，不需要先打开源码。

## 编辑和保存

当前默认模式就是所见即所得。

这意味着：

- 打开文档后，直接看到可编辑正文
- 标题、列表、引用、代码块等都可以直接改
- Markdown 源码不是默认模式，只在需要时打开

常用操作：

- `Ctrl/Cmd + S`：保存
- `Ctrl/Cmd + E`：打开或关闭 Markdown 源码
- `Esc`：关闭源码抽屉或弹窗

如果你想精确改 Markdown，可以点击左侧 `Markdown 源码` 图标，或到 `设置与维护` 面板里打开源码。

## 文件夹和搜索

文件夹管理主要在 `资源管理器` 和 `设置与维护` 中完成。

支持：

- 新建文件夹
- 重命名文件夹
- 删除空文件夹
- 调整文档所属文件夹

搜索在 `搜索` 面板中完成，会搜索：

- 标题
- 正文
- 关键词

## 共享笔记怎么用

打开 `导入与同步` 面板后，你会看到：

- `上传共享笔记`
- `拉取共享笔记`

### 上传共享笔记

上传时需要填写：

- 作者
- 学院
- 专业
- 年级
- 标签
- 简介

上传机制不是“传一个文件”，而是：

- 每个贡献者一个共享分支
- 每个共享分支带一份 `shared_notes/manifest.json`
- GitHub Actions 会把这些分支汇总成中央 `shared_notes/shared-index.json`

点击开始上传后：

- 上传会在后台继续执行
- 你可以关掉弹窗，继续编辑当前笔记
- 右下角会显示上传中 / 成功 / 失败

### 拉取共享笔记

拉取页面会优先读取中央索引，再展示可导入的共享分支。

你可以按这些条件筛选：

- 学院
- 专业
- 年级
- 关键词

导入后，内容会真正落到你的本地工作区，可以继续编辑，不是只读链接。

## 退出站点在哪里

退出功能在左侧 `设置与维护` 面板里，名称是 `退出站点`。

规则是：

- 如果当前是本地服务模式，可以点击它停止服务并离开页面
- 如果当前是静态只读模式，这个按钮会禁用

## 文件保存在哪里

最重要的几个位置：

- 本地文档：`content/imports/`
- 图片资源：`content/assets/`
- 文档索引：`content/library.json`
- 共享分支元数据：`shared_notes/manifest.json`
- 中央共享索引：`shared_notes/shared-index.json`

## 什么时候会提示错误

这些情况会被拦住：

- 输入空网址或非法网址
- 文件夹名称不合法
- 删除非空文件夹
- 在静态模式下执行需要服务端的动作
- 共享上传或拉取时远端 Git / GitHub 配置不完整

看到提示后，按提示修正即可。
