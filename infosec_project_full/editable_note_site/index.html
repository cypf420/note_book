功能说明

无须登录，启动本地服务后直接访问网站即可开始使用

这个站点用于管理本地 Markdown 笔记和网页抓取结果。左侧负责检索、切换和导入网址，中间负责阅读与编辑，保存后会把文件直接写回当前项目目录。

怎么使用

1. 双击 begin.bat，它会自动检查环境、安装依赖并启动网站。

2. 浏览器打开终端提示的网址，默认是 http://127.0.0.1:8000。

3. 在左侧搜索现有文档，或输入网页地址导入内容。

抓取结果保存位置

导入后保存的 Markdown 会写入 content/imports/<slug>.md。

网页里的图片会下载到 content/assets/<slug>/。

文档索引会自动更新到 content/library.json。

编辑与导出

点击“编辑当前文档”进入源码模式，Ctrl/Cmd + S 保存，Esc 返回阅读模式。

“删除当前文档”会删除已保存的导入笔记，并同步清理索引和对应资源目录。

适用场景

适合把课程资料、博客文章、知识库页面抓取为本地 Markdown，再继续整理、检索、维护。

顶部还可以对笔记分组、重命名分组、删除空分组；如果只是用静态服务器打开页面，这些写入类操作会变成只读模式。
