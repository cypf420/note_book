# 新手引导

## 这是什么

这是一个本地笔记工作台，用来把网页内容抓取下来，整理成 Markdown 文档，并继续在浏览器里阅读、编辑、搜索和归档。

它适合这些场景：

- 把课程资料、博客、知识库页面抓成本地笔记
- 把网页里的图片一起保存到本地
- 用分组树把资料按主题整理起来
- 对导入后的 Markdown 继续修改和沉淀

## 这个网站能做什么

### 1. 导入网页

输入网页地址后，可以：

- 先导入到编辑区，确认内容是否合适
- 直接导入并保存到站点

导入时会自动：

- 抓取网页正文
- 下载网页图片
- 把内容转换为 Markdown
- 更新文档索引

### 2. 编辑文档

支持两种方式：

- 阅读模式
- Markdown 源码编辑

常用快捷键：

- `Ctrl/Cmd + S` 保存
- `Esc` 退出编辑

### 3. 管理笔记

顶部的 `笔记树` 按钮可以打开树形导航。

在这里可以：

- 按分组查看笔记
- 折叠或展开分组
- 拖拽调整笔记顺序
- 把笔记拖到别的分组
- 新建分组
- 重命名分组
- 删除空分组

### 4. 搜索笔记

左侧支持全文搜索，可以按标题和正文内容快速定位资料。

### 5. 删除笔记

删除已保存的导入笔记时，会同时清理：

- 对应的 Markdown 文件
- `library.json` 里的索引
- 关联的图片资源目录

## 文件保存在哪里

抓取和保存后的内容主要在下面这些位置：

- 导入笔记：`editable_note_site/content/imports/`
- 网页图片：`editable_note_site/content/assets/`
- 文档索引：`editable_note_site/content/library.json`

## 怎么启动

最简单的方法：

1. 进入 `editable_note_site`
2. 双击 `begin.bat`
3. 浏览器打开终端提示的网址

如果启动成功，终端会显示实际访问地址。

## 使用建议

- 先导入到编辑区，再决定是否保存
- 用分组树整理不同主题的资料
- 定期清理无用导入，保持索引整洁
- 重要资料建议再同步到 Git

## 非法操作提示

为了避免误操作，系统会在这些情况下弹出错误提示：

- 空网址或错误网址
- 非法分组名
- 删除未保存的临时导入内容
- 删除仍然包含笔记的分组
- 未保存就尝试做仅限已保存文档的操作

如果看到错误提示，按提示修正后再操作即可。
